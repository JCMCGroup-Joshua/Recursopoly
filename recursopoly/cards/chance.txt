# Recursopoly Chance deck
# ---------------------------------------------------------------
# One card per line:
#
#     text | effect | key=value; key=value
#
# Effects:
#   move_to              square=<name> (on the player's current board);
#                        collects the Go salary if Go is passed
#   move_by              steps=<n> (negative moves backwards, never pays Go)
#   move_to_nearest      type=station|utility; optional rent_multiplier=<n>
#                        (rent owed there is multiplied by n)
#   collect              amount=<n> from the bank
#   pay                  amount=<n> to the bank
#   collect_from_each    amount=<n> from every other player
#   pay_each             amount=<n> to every other player
#   repairs              house=<n>; hotel=<n> per building owned
#   go_to_jail           straight to jail, without passing Go
#   get_out_of_jail_free kept until used (or traded back to the deck)
#
# The deck is shuffled at the start of every game.
